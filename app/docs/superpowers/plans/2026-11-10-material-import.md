# Доступный импорт и автономный экспорт

**Цель:** завершить ранее согласованные изменения speechread: свободный порядок добавления текста и аудио, перетаскивание файлов, скрываемый плеер и один автономный HTML.

**Архитектура:** обработка файлов остаётся в браузере. Один валидатор обслуживает выбор и перетаскивание. Элемент аудио сохраняется при сворачивании панели, IndexedDB хранит материал и последнюю запись отдельно.

**Стек:** Next.js 16, React 19, TypeScript, IndexedDB, mediabunny.

**Требования:** последние уточнения пользователя из чата «Проверь генерацию статей с озвучкой»: единая форма без обязательных шагов; TXT/Markdown и аудио через drag and drop; плеер отсутствует без аудио и сворачивается при наличии; экспорт MP3 или одного HTML со звуком; автосохранение захвата и оба режима обработки пауз.

- [x] Проверить исходные браузерные сценарии и воспроизвести недоступность аудио на первом шаге.
- [x] Добавить тесты общего валидатора файлов, проверить их падение, реализовать проверку формата, размера и неоднозначных наборов.
- [x] В `Reader.tsx` заменить мастер единой формой, подключить выбор и перетаскивание, сохранить доступ к записи вкладки.
- [x] Скрывать плеер без аудио, сворачивать панель без остановки записи, проверить на мобильной ширине.
- [x] Проверить автосохранение захвата, пропуск пауз, экспорт MP3 и автономного HTML с подсветкой.
- [x] Обновить инструкции и Mermaid, выполнить тесты, проверку типов, сборку и браузерную проверку полного пути.

Проверяемые границы: отмена выбора не сбрасывает файл; ошибочный импорт сохраняет текущий материал; одновременный drop MD и MP3; сворачивание не сбрасывает позицию; HTML работает без соседнего аудиофайла.

Результат: 28 unit-тестов, TypeScript и статическая сборка проходят. Полный браузерный сценарий проверен в Edge на dev-сервере и сборке `out/`, включая синтетическую запись MediaRecorder, автоскачивание и восстановление MP3. После независимого ревью исправлены пропуск пауз при отключённом RAF и гонка чтения Markdown; добавлены браузерные проверки искусственной задержки чтения и приоритета ручного ввода. Повторное ревью не выявило оставшихся существенных замечаний по этим исправлениям.
