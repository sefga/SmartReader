# Выбор способов синхронизации

**Цель:** понятный выбор встроенного распознавания, OpenAI API, Gemini API, готового JSON и промптов для другого чата.

**Решение:** статическая читалка сохраняет встроенный способ по умолчанию. Облачные запросы выполняются только явным действием с собственным ключом в текущем окне; ключ не сохраняется. Серверный прокси потребовал бы отдельной инфраструктуры для GitHub Pages, а только ручной JSON не выполнял бы запрос API из приложения, поэтому выбран прямой BYOK-запрос с ручным способом как альтернативой.
